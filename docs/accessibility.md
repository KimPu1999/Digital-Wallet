# Accessibility Verification

The UI uses semantic headings, labels, buttons, links, focusable controls and responsive layouts in the existing React pages. This is an implementation review, not a completed WCAG 2.2 AA audit.

Required evidence before release:

- Keyboard-only navigation of customer, merchant and admin journeys.
- Focus trapping and return focus for dialogs/drawers.
- Screen-reader announcements for validation, loading and error states.
- Contrast and non-color status verification in light and dark themes.
- Reflow at mobile/tablet/desktop widths.
- Automated axe or equivalent browser scan with reviewed exceptions.
