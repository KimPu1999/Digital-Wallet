# Sandbox Beta Testing

Beta distribution must use isolated sandbox accounts, test provider adapters and clearly labeled test data. Testers must receive credentials through an approved private channel, never from Git. Revoke tester access when the beta ends and remove or redact feedback identifiers.

Required scenarios include login/session expiry, wallet reads, failed network requests, language/theme switching, biometric cancellation, QR validation, and confirmation that no real-money action is available.
