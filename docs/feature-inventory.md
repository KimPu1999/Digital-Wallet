# Feature Inventory

Feature coverage is stored in `qa_module_inventory` and must be populated from test-run, security-review, performance, recovery or release artifacts. The quality center does not infer coverage from a frontend route or a hidden button.

Coverage statuses are `implemented`, `partially_implemented`, `missing`, `broken`, `untested`, and `blocked_external_dependency`. Each record should include a phase, evidence reference, audit timestamp and notes.
