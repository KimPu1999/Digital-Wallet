# Launch governance

The launch readiness endpoint exposes twelve evidence gates and returns `blocked` until every gate is verified. Launch assessment requests create a planning-only pilot and a two-decision maker-checker approval request. A dashboard decision cannot enable production financial execution.

The current environment hard-codes the safety invariant `live_financial_execution_enabled=false` in the readiness responses and existing application configuration. Any future activation must require independent legal, compliance, partner, security, operational, and executive evidence plus an authorized deployment process.
