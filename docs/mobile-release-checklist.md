# Mobile Release Checklist

- [ ] Flutter analysis and tests pass on CI.
- [ ] Android and iOS debug/release builds validate.
- [ ] API base URLs are environment-specific.
- [ ] No secrets or signing files are committed.
- [ ] Sanctum session behavior is validated on physical devices.
- [ ] MFA, KYC, AML and risk controls remain server-enforced.
- [ ] Biometric fallback and logout-all-devices behavior are tested.
- [ ] QR permissions and server-side payload verification are tested.
- [ ] Accessibility, localization and dark-mode review is complete.
- [ ] Store publication has explicit approval.
