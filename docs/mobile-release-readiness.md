# Mobile Release Readiness

Mobile readiness is `ready` only when critical tests, mobile security, performance, accessibility, localization, Android build, iOS build and beta approval have passing stored evidence. Missing evidence is `blocked`; a release candidate cannot be approved from the dashboard alone.

The current local status is **blocked**: Flutter/Dart/Android tooling is unavailable, native projects are not generated, and no mobile build/test artifacts have been imported.
