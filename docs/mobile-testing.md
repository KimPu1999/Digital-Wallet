# Mobile Testing

The repository contains a foundation widget/integration smoke test and a sandbox policy unit test. Flutter, Dart, Android SDK and iOS simulator tooling were unavailable in the current environment, so these tests were not executed here.

Required checks include `flutter analyze`, Dart formatting, `flutter test`, integration tests, Android debug build, iOS no-code-sign build, and device tests for biometrics, camera permissions, session expiry and deep links.
