# Pilot Operations

Pilot programs are created as sandbox drafts. A program records its objective, owner, reviewer, jurisdictions, currencies, allowed sandbox features, provider capabilities, transaction types and operating window.

The operations view reports only database-backed activity and includes freshness timestamps. Missing provider telemetry is shown as unavailable, not healthy. Currency totals remain separate and are reported in minor units.

Operational actions include draft editing, cohort management, participant enrollment and a safe pause action. Closure and evaluation decisions create approval requests and do not automatically activate or settle any financial operation.
