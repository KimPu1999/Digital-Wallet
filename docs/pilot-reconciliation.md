# Pilot Reconciliation

Pilot reconciliation reuses the ledger and provider reconciliation services. Review records retain expected and actual minor-unit amounts, variance, currency, status, owner and evidence references.

Currencies are never combined without explicit valuation metadata. Critical exceptions can block affected pilot capabilities, but the pilot dashboard never edits balances or silently corrects differences. Corrective postings, if ever authorized, must use the existing immutable compensating-entry workflow.
