# Pilot Risk Controls

Pilot participation does not bypass KYC, KYB, AML, sanctions screening, fraud controls, MFA or platform permissions. Open high-risk cases block customer eligibility. Sensitive pilot decisions use maker-checker approvals and audit events.

The current implementation supports sandbox feature identifiers only: wallet checkout, provider checkout, QR, FX quote, transfer simulation and read-only reporting. No live provider capability is accepted by the pilot API.
